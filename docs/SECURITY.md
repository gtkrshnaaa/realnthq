# Security Policy and Responsible Disclosure

The official Security Policy and Vulnerability Disclosure process for `realnthq` is documented in [.github/SECURITY.md](../.github/SECURITY.md).

## Critical Guidelines
* Do NOT report security vulnerabilities via public GitHub issues.
* Submit private advisories via the GitHub Security Advisory portal or email `security@realnthq.org`.
* Active security maintenance is provided for `1.x.x` releases.

See [.github/SECURITY.md](../.github/SECURITY.md) for full SLA details and response timelines.
